# Nosing · 小市唱 V8

小市唱（NSG 歌声合成器）是一款离线歌声合成编辑器。它用声带、口腔和鼻腔等声学模型生成歌声，支持多语言歌词、钢琴卷帘、多条独立人声音层和自动伴奏。

## 快速开始

在 Chrome 或 Edge 中打开 `index.html`，即可加载内置示例或导入自己的工程。浏览器版可以直接离线运行，无需安装依赖。

- 人声默认以 16 kHz 合成，可切换到 48 kHz 的模式 B。
- 支持导出本层人声、全部人声音层的 WAV ZIP、伴奏、混音以及 MIDI。
- 支持简体中文和英文界面。
