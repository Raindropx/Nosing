# 小市唱。！

> 个人主观片面地认为，它们没有在唱歌。-- 达基·基

[English](README.md)

小市唱（Nosing）是一款离线歌声合成器。你画音符，填歌词，点播放，声带、口腔和鼻腔的算法（不是录音回放、不含模型权重）就合伙把这句唱出来。达基·基先生试听后，决定保留原意见。

## 先让它唱个“啊”

1. 用 Chrome 或 Edge 打开 `index.html`。浏览器版可以离线运行，免安装。
2. 加载内置示例，或者导入自己的工程。在钢琴卷帘里挑一个音符，把歌词改成“啊”。
3. 点播放。如果觉得这个“啊”还不足以表达你的心情，就把音符拉长一点。

歌词可以用多种语言写，人声可以分好几层录入，还能开自动伴奏。界面支持简体中文和英文。人声默认以 16 kHz 合成，切换到 HiFi 模式后以 48 kHz 合成。

可以导入 CeVIO（`.ccs`、`.ccst`）、VoiSona（`.tssln`）、DeepVocal（`.dv`）、Sharpkey（`.sk`）、MUTA（`.mtp`）、VocalSharp（`.vspx`）和 Vogen（`.vog`）的人声谱面。可以将所选轨道载入为新工程，也可以附加到现有工程。导入后使用小市唱自己的声源合成，伴奏音频、拍号和原声库不随工程载入。

导出时可以拿走本层人声 WAV、装着全部人声分层 WAV 的 ZIP、伴奏、混音或 MIDI。

## 常见问题

**Q：无中之人有什么好处？**

A：不烧心。

**Q：母鸡为什么要过马路？**

A：为了去马路对面。

**Q：为什么我的歌开头有四秒没有声音？**

A：你把第一个音符放在了 0:05。

**Q：可以合唱吗？**

A：可以。多开一层人声，双方就对这首歌负有同等责任。
